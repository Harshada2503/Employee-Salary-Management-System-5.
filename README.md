
# Employee Salary Management System

## Project Overview
The Employee Salary Management System is a web-based application developed using Java and Spring MVC. It helps manage employee information, salary details, and payroll operations.

## Technologies Used
- Java
- Spring MVC
- JdbcTemplate
- MySQL
- JSP
- HTML
- CSS
- Bootstrap
- Apache Tomcat
- Maven

## Project Architecture
Controller → Service → Repository → Database

## Main Features
- Employee Management
- Salary Management
- Payroll Management
- Salary Calculation
- Salary Slip Generation
- Admin Management

## AI Integration
Ollama is selected for the planned AI-powered Payroll Intelligence module, which will analyze payroll summaries and generate useful insights.

## Database
MySQL

## Development Tools
- Spring Tool Suite (STS)
- MySQL Workbench
- Apache Tomcat
- Git and GitHub

## How to Run the Project
1. Clone this repository.
2. Import the project into Spring Tool Suite.
3. Create the MySQL database.
4. Configure your database credentials.
5. Update Maven dependencies.
6. Configure Apache Tomcat.
7. Run the application.
